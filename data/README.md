# Data

## Raw data (not included)

Raw battery cycling data are **not redistributed** in this repository. They
must be obtained manually from the three public sources:

| Dataset | Source | Place under |
|---|---|---|
| CALCE Battery Research Group (University of Maryland) | https://calce.umd.edu/battery-data | `data/raw/calce/` |
| NASA Ames PCoE Data Set Repository | https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/ | `data/raw/nasa/` |
| Oxford Battery Degradation Dataset 1 | https://ora.ox.ac.uk/objects/uuid:03ba4b01-cfed-46d3-9b1a-7d4a7bdf6fac | `data/raw/oxford/` |

Run `python scripts/download_data.py` to print the same instructions with
per-dataset layout notes. `data/raw/` is gitignored.

## Directory layout

```
data/
├── raw/         # manually downloaded datasets (gitignored, not tracked)
├── processed/   # generated by scripts/preprocess_real_battery.py (not tracked)
└── splits/      # tracked preprocessing outputs and split manifests
    ├── real_battery_manifest.json          # preprocessing run manifest (45 QA-passing cells, seed, package versions)
    ├── real_battery_preprocess_qa.csv      # per-cell QA metrics and pass/fail flags (55 candidate cells, 45 passing)
    ├── real_battery_splits.json            # time-forward, cell-separated train/cal/val/test assignments
    └── real_battery_skipped_sources.json   # cells excluded by QA, with reasons
```

## Rebuilding

```bash
python scripts/preprocess_real_battery.py
```

reads `data/raw/`, applies per-cell QA gating (capacity-spike filtering,
SOH range and monotonicity checks), and writes the cycle-level SOH tables to
`data/processed/` plus the split artifacts under `data/splits/`. All
experiment runners consume `data/processed/real_battery_cycle_level_features.csv`
and the split manifest; no synthetic rows are generated anywhere.
