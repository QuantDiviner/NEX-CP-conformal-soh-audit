# 投稿声明模板

本目录包含学术论文投稿常用的声明模板。

## 声明列表

| 文件 | 用途 | 何时需要 |
|------|------|----------|
| `author_contributions.md` | 作者贡献声明 | 几乎所有期刊 |
| `conflict_of_interest.md` | 利益冲突声明 | 几乎所有期刊 |
| `funding.md` | 资金来源声明 | 有资助时 |
| `ethics.md` | 伦理声明 | 涉及人类/动物研究 |
| `data_availability.md` | 数据可用性声明 | 大多数期刊要求 |
| `code_availability.md` | 代码可用性声明 | 越来越多期刊要求 |

## 使用方法

1. 复制需要的模板到论文目录
2. 填写具体信息
3. 根据期刊格式整合到论文中

## 注意事项

- 不同期刊对声明格式有不同要求，请查阅目标期刊指南
- 某些期刊要求在投稿系统中单独填写，而非放在论文中
- 保持诚实，如实填写
