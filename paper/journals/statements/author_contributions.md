# 作者贡献声明 (Author Contributions)

## CRediT 标准格式

使用 [CRediT (Contributor Roles Taxonomy)](https://credit.niso.org/) 标准：

---

**[Author 1 Name]**: Conceptualization, Methodology, Software, Validation, Formal analysis, Investigation, Writing – original draft, Visualization.

**[Author 2 Name]**: Conceptualization, Methodology, Supervision, Writing – review & editing, Project administration, Funding acquisition.

**[Author 3 Name]**: Resources, Data curation, Writing – review & editing.

---

## CRediT 角色说明

| 角色 | 英文 | 说明 |
|------|------|------|
| 概念化 | Conceptualization | 提出研究想法和目标 |
| 方法论 | Methodology | 设计研究方法 |
| 软件 | Software | 编程和软件开发 |
| 验证 | Validation | 验证结果的正确性 |
| 形式分析 | Formal analysis | 统计分析和数据处理 |
| 调查研究 | Investigation | 执行实验或数据收集 |
| 资源 | Resources | 提供材料、仪器等 |
| 数据管理 | Data curation | 数据管理和维护 |
| 撰写初稿 | Writing – original draft | 撰写论文初稿 |
| 审阅编辑 | Writing – review & editing | 审阅和修改论文 |
| 可视化 | Visualization | 创建图表 |
| 监督 | Supervision | 指导研究 |
| 项目管理 | Project administration | 管理研究项目 |
| 获取资金 | Funding acquisition | 获取研究资金 |

## 简化格式

部分期刊接受简化格式：

---

All authors contributed to the study conception and design. Data collection and analysis were performed by [Author 1]. The first draft was written by [Author 1], and all authors commented on previous versions of the manuscript. All authors read and approved the final manuscript.

---

## 注意事项

- 所有作者必须对论文有实质性贡献
- 仅提供资金、材料或一般监督不足以成为作者
- 所有作者必须审阅并批准最终版本
