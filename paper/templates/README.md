# Submission Template Assets

Downloaded / refreshed: 2026-06-02

## Elsevier `elsarticle`

Path: `paper/templates/elsevier/`

This directory contains the CTAN `elsarticle` package assets used for final
Elsevier LaTeX packaging: template `.tex` files, BibTeX styles, documentation,
and generation sources (`elsarticle.ins`, `elsarticle.dtx`). The class file is
normally provided by TeX Live or can be generated from the included sources.

## Quarto Elsevier

Path: `paper/templates/quarto-elsevier/`

This is the generic `quarto-journals/elsevier` extension snapshot. It is not
RESS-specific. The governed working draft remains `paper/source/paper.qmd`;
final packaging may either add this extension to the source project or flatten
the rendered LaTeX to official Elsevier `elsarticle` assets.
